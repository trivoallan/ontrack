# Solution Strategy

| Choice | Why | Detail |
| --- | --- | --- |
| Plan, then apply | `plan` computes what would change, as data, and writes nothing. `apply` builds the same plan, checks every action against it, and only then writes. A CI job can run `plan` safely, and an error in `apply` never leaves a half-applied repository. | [plan](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/plan/spec.md), [apply](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/apply/spec.md) |
| npm is the transport | A track is an npm dependency, so versions, authentication, the lockfile and offline installs are npm's. ontrack reads `node_modules` and never downloads anything. The npm alias is the namespace, which lets a project choose the directory name of each track. | [tracks](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/tracks/spec.md), [ADR-0012](../../adr/engineering/ADR-0012-delivery.md) |
| Compare revisions, not content | The local copy of an ADR holds the repository's ruling, so it always differs from the track's copy. Only the integer `revision:` is compared: it moves when the convention changes, and that is the only time an answer must be taken again. | [adr-revision](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/adr-revision/spec.md) |
| Read frontmatter without a YAML parser | ontrack needs a few top-level keys from files it did not write. A line scanner between the two fences finds them, leaves every other byte of the file as it was, and saves a dependency. Trait blocks are copied verbatim and never interpreted. | [adr-revision](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/adr-revision/spec.md), [instructions](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/instructions/spec.md) |
| Validate what comes from outside in one place | The shapes of the project's `package.json`, of a track's `package.json` and of the frontmatter values ontrack uses are zod models in one module. A value a model refuses becomes an error that names the field, or counts as "no value"; it never travels further. | [ADR-0005](../../adr/engineering/ADR-0005-validation.md), [tracks](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/tracks/spec.md) |
| Own one block of `AGENTS.md`, nothing else | The rulings reach coding agents through a file they already read. ontrack owns the text between two markers and leaves the rest of the file to its authors. | [agents-file](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/agents-file/spec.md) |
| Print a prompt, do not run an agent | Ruling an ADR, or finding the decisions a repository never recorded, needs judgement and the user's agreement. `review` and `suggest` print fixed text plus paths; the agent reads the repository, and which agent reads the prompt is the user's choice. | [review](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/review/spec.md), [suggest](https://github.com/trivoallan/ontrack/blob/main/openspec/specs/suggest/spec.md), [ADR-0029](../../adr/local/ADR-0029-ontrack-prints-the-prompt-the-agent-reads-the-repository.md) |
| One monolithic package | The tool is small: its modules are files that call each other. | [ADR-0003](../../adr/engineering/ADR-0003-architecture.md), [Building Block View](05-building-block-view.mdx) |
