<div class="features">

- **[Share conventions](features.md#share-conventions)**
  Written once, in a track.
- **[Rule on each convention](features.md#rule-on-each-convention)**
  Your ruling, drafted by an agent.
- **[Instructions in the harness](features.md#load-the-instructions-into-the-agents-harness)**
  One block in `AGENTS.md`.
- **[A compliance backlog](features.md#keep-the-repository-true-to-its-rulings)**
  One issue per ruling not followed yet.
- **[Revisions reported](features.md#know-when-a-convention-changes)**
  `ontrack plan` exits with `2`.
- **[No lock-in](features.md#no-lock-in)**
  Markdown files, an npm dependency, no server.
