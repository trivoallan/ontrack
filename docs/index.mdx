<div class="features">

- **[Share conventions](features.md#share-conventions)**
  Written once, proposed to every repository.
- **[Rule on each convention](features.md#rule-on-each-convention)**
  Follow, depart or reject. An agent drafts it.
- **[Brief your agents](features.md#load-the-instructions-into-the-agents-harness)**
  Your rulings, in the `AGENTS.md` they already read.
- **[Stay true to your rulings](features.md#keep-the-repository-true-to-its-rulings)**
  An issue per gap, then a check in CI.
- **[Know when a convention changes](features.md#know-when-a-convention-changes)**
  `ontrack plan` names each one to rule on again.
- **[No lock-in](features.md#no-lock-in)**
  Markdown files, an npm dependency, no server.
